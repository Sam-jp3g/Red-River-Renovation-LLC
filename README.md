# Red River Renovation, LLC — Our Work Gallery

This package replaces the original GitHub Pages gallery and **includes all selected photo files**.
It requires no Google Drive access, API keys, or external services.

## Contents
- `index.html` — complete updated, responsive website and all image references.
- `photos/` — selected photographs, organized by renovation project and compressed as browser-ready WebP images.
- `project-manifest.json` — list of categories, projects, selected filenames, and skipped duplicates.

## Preview on your Mac
Extract the ZIP, then open `index.html` in Safari or Chrome. All pictures should display without internet access.

## Publish to GitHub Pages
1. Open your existing `Red-River-Renovation-LLC` repository on GitHub.
2. Replace the old root `index.html` with the new `index.html`.
3. Upload the **entire `photos` folder**, retaining all its subfolders. Use GitHub Desktop if your browser won't upload folders easily.
4. Commit the changes to the branch publishing GitHub Pages (usually `main`).
5. After GitHub Pages rebuilds, hard-refresh your gallery page.

To get the optional **BACK TO MAIN WEBSITE** link, find `const MAIN_WEBSITE_URL = '';` near the end of `index.html` and paste your live Canva website URL between the quotes.

## Photo selection
Included 33 projects and 146 photographs across eight categories.
We prioritized completed-project images, clear shots, and useful progress sequences where they were available in the supplied Drive folders. Some works-in-progress appear intentionally in the individual project galleries.
Only published project photos are included. Source images were not edited or deleted in Google Drive.

For best results, verify that the renovation company/client approves the selected images for public use before publishing.
